## 快速开始

不需要安装任何依赖，直接打开 `index.html` 即可使用（数据保存在浏览器 localStorage）。

```
start index.html
```

或启动本地服务器（**推荐**，内嵌的子应用加载更稳定）：

```
python -m http.server 8080 --directory "D:\dsh workspace"
# 浏览器访问 http://127.0.0.1:8080/
```

> 更新文件后请按 `Ctrl + F5` 强制刷新，避免浏览器缓存旧版本。

### 内嵌子应用的协作方式

「100句记7000词」和「单词听写训练营」都是**独立完整的单页应用**，本站通过 iframe 内嵌，并传入 `?embed=1`：

- 被嵌入时，子应用会隐藏自身品牌栏（保留句子单元导航 / 快捷键按钮），避免与外层导航重复
- **单独打开时不受影响**：`apps/ielts-sentences/index.html`、`apps/tingxie/index.html` 保持原有完整界面
- iframe 采用**懒加载**：只有首次切换到对应模块时才请求（100句应用含 863KB 数据，避免拖慢首页）
- 每个内嵌模块右上角都有「↗ 全屏打开」按钮

## 单词模块

### 子模块 1：阅读538词汇

#### 词库数据（376 个单词，全部来自 kaodianciku.pdf）

词库严格取自《kaodianciku.pdf》雅思阅读考点词库（引用于刘洪波《剑桥雅思阅读考点词真经》），
按书中的重要性排序分为三类考点词（**重要性由类别体现，不再用星级表示**）：

| 类别 | 数量 | 说明 | 学习要求 |
|------|------|------|----------|
| 第1类考点词 | 20 | 阅读文章中出现该词约 **90%** 会被命题考查 | 滚瓜烂熟 |
| 第2类考点词 | 100 | 出现该词约 **60%** 会被命题考查 | 熟记 10 遍以上 |
| 第3类考点词 | 256 | 真题中被考查过的单词，重要性一致、书中未排序 | 熟记 5 遍以上 |

每个词条包含：单词 / 词性 / 中文释义 / **真题同义替换**（命题方式）。
其中 `that`、`and`、`rather than`、`thanks to` 四个结构词附有考点注解（指代/并列/转折/因果是雅思阅读重要考点）。

### 掌握程度星级（1-5★）

星级表示**你对单词的掌握程度**，由复习进度自动计算，无需手动设置：

| 星级 | 含义 | 对应复习间隔 |
|------|------|--------------|
| 1★ | 未学习，或刚标记"不认识" | — / 10分钟 |
| 2★ | 答过"认识" | 1 天 |
| 3★ | "已掌握"过一次 | 3 天 |
| 4★ | 复习巩固中 | 6 天 |
| 5★ | 长期记忆 | ≥12 天（最高30天）|

作答后提示条会显示掌握度升降，例如：`resemble：已掌握（3 天后复习）　掌握度 1★ → 3★`。

### 侧边栏：三类考点词掌握分布

每类考点词用一条**三色分段条**显示不同掌握程度的单词数量：

- 🟢 **绿色 = 已掌握**（掌握度 ≥3★）
- 🟡 **黄色 = 学习中**（有学习记录但仅 1-2★）
- 🔴 **红色 = 未学习**（尚无记录）

分段条下方同时给出三类的具体词数。

#### 功能一：闪卡复习（间隔重复 SRS）

- **自选复习范围**：`全部随机` / `第1类考点词` / `第2类考点词` / `第3类考点词`，按钮上显示各类词数
- **自动发音**：出现新单词时自动朗读，默认**英音（en-GB）**
- **手动发音**：卡片下方 `🔊 英音` / `🔊 美音` 两个按钮，可随时切换口音试听
- 卡片正面显示该词**当前掌握度星级**；点击卡片翻面查看释义与真题替换词
- 三个按钮评价熟悉程度，自动安排下次复习时间：

| 按钮 | 行为 | 下次复习 |
|------|------|----------|
| 😵 不认识 | 重置进度 | 10 分钟后 |
| 🤔 认识 | 进度+1 | 1 天后 |
| ✅ 已掌握 | 进度+1 | 3天 → 6天 → 12天…（翻倍，上限30天）|

- 连续 3 次"已掌握"后标记为 🎓 已掌握
- 出题顺序：**到期优先** → 未学新词（随机抽取）→ 未到期复习词
- 侧栏显示：当前范围进度、三类考点词掌握分布（三色分段条）、今日待复习清单、间隔规则
- 键盘快捷键：`空格` 翻面，`1` 不认识，`2` 认识，`3` 已掌握，`P` 重放发音

#### 功能二：词汇表

- 376 词按三类考点词分组全部列出
- **排序**（组内排序，类别分组保持不变）：
  - `字母顺序`：A→Z
  - `掌握度 高→低`：5★ 词排前面
  - `掌握度 低→高`：1★ 词排前面
- **筛选**：掌握度（5★/4★/3★/2★/1★）与类别（三类考点词）
- **搜索**：中英文均可（支持按释义、同义替换词搜索）
- 每个单词展示：词形 / 掌握度星级 / 词性+中文释义 / 真题同义替换，并标注状态徽章（✓已掌握 / 学习中）

## 学习记录的存储与跨设备同步

### 数据存在哪里

全部学习记录保存在浏览器的 **localStorage**，本站**不发起任何网络请求**，数据不会离开你的设备。

| 模块 | 存储键 | 内容 |
|------|--------|------|
| 单词 · 阅读538词汇 | `ielts_words_progress_v1` | 每个词的 SRS 状态（掌握度星级 / 复习间隔 / 到期时间） |
| 单词 · 阅读538词汇 | `ielts_settings_v1`、`ielts_scope_v1`、`ielts_sort_v1` | 发音口音与语速、复习范围、排序偏好 |
| 听力 · 单词听写 | `ielts_tingxie_srs_v1` | 每个词的掌握度与错误次数 |
| 听力 · 单词听写 | `ielts_tingxie_exams_v1`、`ielts_tingxie_mistakes_v1`、`ielts_tingxie_settings_v1` | 模考记录、错题本、设置 |
| 单词 · 100句记7000词 | （无） | 纯浏览型，不记录进度 |

### ⚠️ 重要使用提醒（单设备使用）

localStorage 按 **设备 × 浏览器 × 域名(origin)** 三重隔离，因此：

1. **进度不会在设备之间同步**，也不会随浏览器账号（Chrome/Edge 账号同步）同步；
2. 同一台机器上 `file://`、`localhost:8080`、`localhost:8000`、`*.github.io` 是**四个不同域名**，
   各自一套独立记录 —— 建议**固定用同一个地址**学习（推荐固定域名 + 固定端口，例如始终用 Pages 地址或始终用 `localhost:8080`）；
3. **清除浏览器数据、使用无痕模式**会丢失全部进度，请避免；
4. 建议始终在**同一台主设备**上学习，保持记录连续。

### 手动备份 / 迁移进度（无需改代码）

在旧设备的浏览器控制台（F12 → Console）执行，导出为一段文本：

```js
copy(JSON.stringify(Object.fromEntries(
  Object.entries(localStorage).filter(([k]) => k.startsWith('ielts_'))
)))
```

把输出的文本保存好（或发给自己）；在新设备**同一地址**打开站点后，控制台执行：

```js
(() => { const d = JSON.parse(prompt('粘贴进度数据')); Object.entries(d).forEach(([k, v]) => localStorage.setItem(k, v)); location.reload(); })()
```

即可完整迁移单词与听力的全部进度。

### 将来想加自动同步可选的三条路

| 方案 | 原理 | 代价 |
|------|------|------|
| ① 导出/导入 | 生成进度码/文件，另一台设备导入并按「取更熟练的一方」合并 | 需新增约 100 行代码；手动同步，但离线可用 |
| ② GitHub Gist | 用仅 `gist` 权限的令牌把进度写进私有 Gist，各设备自动拉取/上传 | 每台设备需粘贴一次令牌；需联网 |
| ③ Supabase（同步码） | 免费云数据库，用自定义同步码代替账号 | 需注册免费项目并提供 URL + anon key；数据存于第三方 |

三种方案可以叠加（①作为离线兜底，②或③做自动同步），互不冲突。

### 本机网络环境说明

- `github.com` 的 22/443 端口被代理工具通过 DNS 劫持到 `127.0.0.1`，直连不通；
  已在 `~/.ssh/config` 中配置 `github.com → ssh.github.com:443`（GitHub 官方备用端口）绕过。
- 沙箱/受限环境下 git 无法通过 `sh` 传参给 ssh，因此用 `GIT_SSH` 直接指定 ssh 可执行文件。
- 连接时若提示 `Failed to add the host to the list of known hosts`，属已知的写权限限制，
  不影响推送；如需消除，可自行执行：
  ```
  ssh-keyscan -p 443 ssh.github.com >> %USERPROFILE%\.ssh\known_hosts
  ```
