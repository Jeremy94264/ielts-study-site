# 雅思听力语料库 · 听写训练营

从《雅思王听力语料库-3》扫描版 PDF 提取的 **Chapter 3** 单词，按 **Test Paper 1–9** 分组，
做成「**只听发音、键盘拼写、自动判分**」的听写练习网页。

## 快速开始

不需要任何依赖。**推荐用 Chrome 或 Edge 打开**（需要 Web Speech API 朗读单词）：

```
直接双击：tingxie\index.html
```

或启动本地服务器：

```
python -m http.server 8080 --directory "D:\dsh workspace"
# 浏览器访问 http://127.0.0.1:8080/tingxie/
```

> 也可以用 `file://` 直接打开，本模块不依赖 fetch，所有数据用 `<script>` 载入，无跨域问题。

## 功能

### 1. 只听声音，不看词
- 单词只朗读、不显示；用键盘拼写，**Enter 提交，自动判分**
- 拼写判分：忽略大小写与首尾空格，允许 `the/a/an` 冠词冗余，`'` 全角/半角兼容
- **判分后不自动跳题**：显示结果等你确认，再按一次 **Enter**（或点「下一个」）才进入下一个单词
- 答对显示 ✓ + 单词 + 音标 + 释义，并给出 **⭐ 标记为太简单** 按钮（见下）
- 答错显示正确答案，并且**本题会在本组结尾再考一次**

#### 判分后的两个按钮

| 情形 | 按钮 | 作用 |
|------|------|------|
| 答对 | **⭐ 标记为太简单** | 熟练度直接拉满到 5，复习间隔拉到 7 天，这个词不再占用后续复习名额 |
| 答对 | 下一个 `⏎` | 进入下一个单词 |
| 答错 / 跳过 | 其实对了 `1` | 把刚才的误判改成答对 |
| 答错 / 跳过 | 太简单 `3` | 改判为答对，并直接拉到最高熟练度 |
| 答错 / 跳过 | 下一个 `⏎` | 进入下一个单词 |

点「标记为太简单」后会立即显示 `✓ 已标记为熟练` 并禁用该按钮，
**不会自动跳题**，等你按 `Enter` 再走。

> 实现上它调用 `SRS.promote()`：只提升熟练度和复习间隔，**不重复累加作答次数**
> （这次作答已经由 `judgeCurrent()` 记过一次），所以正确率统计不会被污染。

### 2. 每次测试单词数（整十）
`−/＋` 按 **10** 递增，也可点预设 `10 / 20 / 30 / 50 / 100 / 全部`，下限锁 10。

### 3. 合理的复习顺序（正确率 + 熟练度）

每个单词独立记录：熟练度 `st`(0–5)、累计对错、最近 5 次作答、上次作答时间、下次复习时间。
综合优先级公式：

```
prio = 0.85 × 应付系数 + 0.70 × 到期系数 + 0.25 × 新鲜度
       应付系数 = 弱点分 × 新近度修正
```

其中「弱点分」由 **累计正确率 45% + 近 5 次正确率 55%** 加权后再乘以 `(1 - st/5)`，
也就是：**错得越多、越不熟 → 分越高；刚写错的还会再额外加分。**

熟练度决定复习间隔：

| 熟练度 | 判定 | 下次复习 |
|-------|------|---------|
| 0 | 一直写错 | 10 分钟后 |
| 1 | 有点印象 | 30 分钟后 |
| 2 | 勉强记得 | 8 小时后 |
| 3 | 基本掌握 | 1 天后 |
| 4 | 熟练 | 3 天后 |
| 5 | 已熟练 | 7 天后 |

答对 `st+1`，答错 `st-1`（最低 0），点「太简单」直接跳到 `st=5`。
**跳过和「看答案」都按答错处理**：扣熟练度、显示正确答案、并安排本组内重考。

四种出题方式：
- **🧠 智能复习**（默认）：到期 / 薄弱的先用，全新词其次，已熟练且未到期的垫底
- **🎯 只练不熟的**：跳过已熟练词
- **✨ 只学新词**：只抽从没听写过的词
- **📖 按书顺序**：严格按原书顺序，不走算法

### 4. 快捷键

| 按键 | 作用 |
|------|------|
| `空格` | 重听当前单词（输入框为空时） |
| `Enter` | 提交答案；判分后再按一次进入下一个单词 |
| `Ctrl+Enter` | 不会，直接看答案（按错误处理） |
| `Tab` | 不会，跳过；显示答案并按**错误**处理，稍后重考 |
| `1` | 判对（答案被误判为错时） |
| `2` | 判错 |
| `3` | 标记「太简单」，直接跳到熟练 |
| `Esc` | 结束本组 |
| `↑` / `↓` | 调整语速 |
| `?` | 打开快捷键说明 |

### 5. 其他
- 朗读设置：自动朗读、答错后重读、**英美双音**（先英音后美音）、语速 0.5–1.3×、音量、发音人选择
- 结果页：正确率 + 答对 / 答错 / 拼错 / 跳过·不会 / 错题重练 五项统计，逐题明细（可点 🔊 重听，标注跳过与看答案的题目）
- 首页实时显示各 Test Paper 的 **已练 / 熟练 / 待复习 / 平均正确率**
- 学习进度存在浏览器 `localStorage`（键 `ielts_tingxie_srs_v1`），可一键清空
- 响应式布局，手机也能用（移动端用屏幕键盘输入）

### 6. 词表页（📚 查看词表）

用来核对 OCR 提取结果，也可以当**复习清单**翻看。

**三种排序**（选择会记住，下次打开还是这个排序）：

| 排序 | 顺序 |
|------|------|
| 🔤 字母顺序 | 按原书顺序，方便对照纸质书核对 |
| 📈 熟练度 高 → 低 | 已熟练的在前，**没练过的垫底** |
| 📉 熟练度 低 → 高 | **没练过的排最前**（最适合找该背的词），已熟练的垫底 |

熟练度相同时按正确率排，再相同则按字母顺序，保证顺序稳定可预期。
排序可以和搜索叠加使用。

每行右侧用 **5 个小方块**直观显示熟练度（实心 = 已达等级，空心 = 未练过），
后面跟正确率百分比。

列的顺序是：🔊 · 单词 · 音标 · 释义 · 熟练度。所有列统一左对齐，
且各列宽度固定 —— 这一点很关键：一开始音标列用了 `auto`、单词列用了 `minmax()`，
导致每行按各自内容宽度伸缩，释义列左边界最大相差 11px，看起来参差不齐。
改成固定列宽后所有行列边界完全一致。

手机上音标列会让位隐藏，但**释义移到第二行整行显示**，保证中文释义一定看得到。

### 7. 拼写小测（📝）

设置页底部「📝 拼写小测」进入。和平时听写是**两套独立模式**：

| | 平时听写 | 拼写小测 |
|---|---|---|
| 范围 | 自选多个 Test Paper，抽 N 词 | **一次一个** Test Paper，**测完整篇** |
| 错词 | 本组结尾**再考一次** | **不在本轮重复出现** |
| 对错统计 | 计入正确率与熟练度 | **不计入**平时听写的正确率 |
| 错词处理 | 熟练度 -1 | 熟练度 -1 **并写入错题本** |
| 成绩 | 不存档 | **每次存档**，可看正确率曲线 |

三个开关：打乱顺序、每答完立即显示对错、允许跳过（跳过的也算错题）。

#### 错题本

拼错和跳过的词都会进错题本，记录**错误次数、来源（拼错/跳过）、最近出错时间、当前熟练度**。
可以按 Test Paper 筛选、只看未订正的、单条删除。

点「🎧 练习这些错词」会用这些词发起一次专项练习，**答对即视为订正**（标记为「已订正」并从待订正数里扣除）。

#### 测验记录与正确率曲线

每次小测结束都会存一条记录：时间、Test Paper、总词数、对/错/跳过数、正确率、用时、错词列表。

- **折线图**：纯 SVG 手写（无第三方库），纵轴固定 0–100%，便于不同次直接比较；
  悬停数据点显示当次成绩；60% 处有虚线及格线
- 记录列表：按篇筛选，可展开查看当次错词
- 顶部摘要：次数、平均、最好、最差、**趋势**（最近 3 次均值 − 最早 3 次均值）

> 关于趋势：只有 1–2 次记录时，首尾窗口完全重叠，趋势必然是 0。要 3 次以上才有意义。

#### 两个实现上的注意点

1. **小测不污染平时统计。** 小测答错调用的是 `SRS.lower()` 而不是 `SRS.grade()`：
   只降熟练度、重置连续答对、安排尽快复习，**不动 `ok` / `all` / 近 5 次记录**。
   否则一次摸底小测会把平时听写积累的正确率数据搞乱。

2. **小测错词要真的能排上复习队列。** 一个"平时每次都对、但小测写不出来"的词，
   正确率是 100%、熟练度是满的，按弱点公式算出来弱点分接近 0，
   **永远排不到复习队列前面** —— 而这恰恰是小测最该暴露的问题。
   所以 `weakness()` 里对 `examWrong > 0` 的词额外加了权重，
   保证小测错过的词会被优先安排。

## 数据再生成流程（如需更新词表）

脚本都在 `..\extraction\`：

1. `render_hi.py` — 用 PyMuPDF 把 PDF 每页渲染成 300dpi PNG（31 页）→ `pdf_pages_hi/`
2. `ocr_run.ps1` — 调 Windows OCR 逐页识别，输出 `ocr_out/p1..31.txt`
3. `qs_crawl.py` / `qs_dict.py` — 抓取公开词表，生成 `qs_groups.json` / `qs_dict.json`
4. `gloss.py` — 释义回退模块（单数化 / 派生还原 / 人工补充表都在这）
5. `build_words.py` — 清洗 OCR 噪声、按 Test Paper 分组、补全释义 → `words_by_paper.json`
6. `gen_data.py` — 生成 `tingxie/data/paperN.js`

数据文件字段：`w` 单词、`m` 释义、`ipa` 音标、`d:1` 释义为人工补充、`ipad:1` 音标借自单数形式。

## 已评估并放弃：导入剑桥真题听力音频

曾考虑用真实剑桥真题录音替换系统合成语音，**已确认不可行，不再计划做**：

1. 剑桥听力音频有版权，需要使用者自行提供文件，项目内不会分发；
2. 更关键的是**缺少词到音频的映射** —— 本书 Chapter 3 只有按字母序排列的单词表，
   PDF 经检查无内嵌音频、无书签、无时间戳，全书 OCR 文本中也没有任何指向具体真题/Section 的标注。
   要让程序在录音里定位到某个单词，必须对整段录音做 ASR 转写 + 强制对齐来重建映射，
   工程量很大且切分准确率无法保证。

因此**发音继续使用系统语音合成**（Web Speech API）。在本机 Chrome/Edge 上会优先选用
英音自然音色（如 `Microsoft Sonia Online (Natural) - en-GB`），对单词发音练习已经够用。
