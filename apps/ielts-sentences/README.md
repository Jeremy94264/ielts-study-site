# 100个句子记完7000个雅思单词 · Sentence 01–100 学习页

数据来自两册 PDF，共 **100 个单元**（每句一单元）：

| 来源 | 单元 |
| --- | --- |
| `100个句子记完7000个雅思单词001-010.pdf` | Sentence 01–10 |
| `100个句子记完7000个雅思单词_011-100.pdf` | Sentence 11–100 |

## 打开方式

直接双击 `index.html` 即可（纯静态，无需服务器、无需联网）。

## 页面结构

```
┌─────────────────────────────┐
│  句子块（Sentence 01…100）     │   ← 只显示当前单元的句子
├─────────────────────────────┤
│ 句子翻译 │ 语法结构 │ 重点单词 │ 主题单词 │   ← 中间 4 个按钮
├─────────────────────────────┤
│  内容块                        │   ← 随按钮切换显示对应内容
└─────────────────────────────┘
```

顶部有 100 个单元按钮（每 10 句用组号分隔）与左右箭头，可切换句子。

**快捷键**：`←` `→` 上一句/下一句，`↑` `↓` 跨 10 句，`1`–`4` 切换四种模式。
地址栏带 `#u=37&m=vocab&w=issue` 形式的深链接，可直接分享/收藏某个状态。

## 四种模式的行为

| 按钮 | 句子块 | 内容块 |
| --- | --- | --- |
| **句子翻译** | 显示英文原句（衬线字体、居中） | 只显示该句对应中文翻译 |
| **语法结构** | 用**不同颜色荧光笔**把各语法结构标出来，下方出现颜色图例（**图例只在语法结构模式出现**） | 显示文档「语法笔记」原文 + 逐段结构拆解表 |
| **重点单词** | 「核心词表」中的词在句中显示为**红色下划线**，可点击 | 先清空，点击句中单词后显示该词全部内容（音标 / 词性与释义 /【记忆】【搭配】【同义】【同根】【参考】【反义】） |
| **主题单词** | **纯句子，不加任何标记** | 按「主题归纳」的分组列出按钮，选择分组后显示该组全部单词卡片 |

再次点击同一个按钮可取消该模式（回到初始态）。

排版比例：句子块高度上限为视口的 32%（长句在块内滚动），其余空间全部留给内容块。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架：句子块、4 个按钮、内容块 |
| `styles.css` | 全部样式（含荧光笔配色、红色下划线、响应式） |
| `data.js` | 100 个单元的结构化数据：句子、翻译、出处、语法笔记、语法结构切分、核心词表、主题归纳分组 |
| `app.js` | 交互逻辑：模式切换、句子块渲染、重点单词定位与高亮、分组切换 |

数据规模：100 句 · 769 个核心词条 · 186 个主题分组 · 4798 个主题词 · 592 个语法结构片段。

## 数据与实现要点

- **语法结构切分**：`data.js` 中每个单元的 `segments` 是「文本片段 + 语法标签」的数组，所有片段拼起来与 `sentence` **逐字符完全一致**（生成时强制校验），因此荧光笔标注不会改变句子本身。
  - Sentence 01–10 的结构切分是逐句人工核对后写入的（数据里标记 `segSource: 'hand'`）。
  - Sentence 11–100 的结构切分由脚本从「语法笔记」自动推导（标记 `segSource: 'auto'`）：先在中文笔记中确认某个连词/关系词确实被描述为"引导某类从句"，再把该词在句中的位置向外扩展到逗号等自然边界，其余部分归为主句主干。
- **重点单词定位**：`app.js` 会把核心词表的词条与句子做匹配，支持常见词形变化
  （`stifle→stifled`、`produce→producing`、`biologist→biologists`、`show round→shown round`、`world war→world wars` 等），
  并按「长词优先、区间不重叠」标注。
- **保真说明**：按文档原样处理。个别词条虽在「核心词表」中，但原句不含该词形（例如 Unit 05 的 alarm / anxious / uneasy、Unit 09 的 `contain`，句中实际是 `container`），
  这类词在句中不会有红色下划线，但仍可在内容块中查看其完整释义。
